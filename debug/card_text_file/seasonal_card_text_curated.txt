`seasonal_card_text.txt` remains the raw OCR dump.
This file contains only the entries that have been manually reviewed so far.

Notes:
- Unnumbered template PNG entries are marked as unreliable when the text could not be trusted.
- `梦·灵气灌注` and `梦•灵气灌注` are the same card family in practice; the cleaned text below is the curated version for that family.
- Some lines were cross-checked against yi-sim behavior where the OCR was visibly broken.
